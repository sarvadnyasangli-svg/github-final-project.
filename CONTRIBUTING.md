# Contributing to Simple Interest Calculator

Thank you for your interest in contributing! All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Fork** the repository: https://github.com/sarvadnyasangli-svg/Coursera
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/<your-username>/Coursera.git
   cd Coursera
   ```
3. **Create a branch** for your change:
   ```bash
   git checkout -b my-change
   ```
4. **Make your changes** and test them.
5. **Commit** your work with a clear message:
   ```bash
   git add .
   git commit -m "Describe your change"
   ```
6. **Push** your branch to your fork:
   ```bash
   git push origin my-change
   ```
7. **Open a pull request** against the `main` branch.

## Reporting Bugs
Open an issue and include:
- What you expected to happen
- What actually happened
- Steps to reproduce the problem

## Suggesting Enhancements
Open an issue describing your idea and why it would be useful.
